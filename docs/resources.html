Resources

Free books, documentation and tools that go with the tutorials and projects

Free books on R, Python, statistics and bioinformatics, the documentation for the packages used in the tutorials, and where to get R, RStudio, Python and Quarto. Collected by Devon Allies.

Everything here is free to read or use online. Each entry says which of my tutorials, articles or projects it goes with, so you can go deeper on the part you’re working on.

Free books

R · tidyverse

R for Data Science (2nd edition)

Hadley Wickham, Mine Çetinkaya-Rundel and Garrett Grolemund

The place to start with R: importing, tidying, transforming and visualising data with the tidyverse.

Goes with: Tutorial 1: Importing data and Tutorial 3: Cleaning data

R · figures

ggplot2: Elegant Graphics for Data Analysis (3rd edition)

Hadley Wickham, Danielle Navarro and Thomas Lin Pedersen

How ggplot2 works, from the grammar of graphics to scales, facets and themes. The online third edition is still being written.

Goes with: the figures in Choosing the right statistics for cytokine data and every tutorial

Statistics

Introductory Statistics for the Life and Biomedical Sciences

Julie Vu and David Harrington (OpenIntro)

An introduction to statistics built on biomedical examples. The PDF is free (you can set the price to $0).

Goes with: Tutorial 4: Statistical tests and the guide to choosing a test

Statistics

Introduction to Modern Statistics (2nd edition)

Mine Çetinkaya-Rundel and Johanna Hardin (OpenIntro)

A modern introduction that teaches randomisation and bootstrapping alongside the classical tests.

Goes with: Tutorial 4: Statistical tests

Statistics · R

APS 240: Data Analysis and Statistics with R

Dylan Z. Childs, Bethan J. Hindle and Philip H. Warren

A university course book that teaches statistics and R together for biologists, with clear chapters on assumptions, transformations and paired designs.

Goes with: Tutorial 4: Statistical tests and Choosing the right statistics for cytokine data

Python · pandas

Python for Data Analysis (3rd edition)

Wes McKinney

Data wrangling in Python with pandas and NumPy, by the creator of pandas. Free to read online.

Goes with: Tutorial 2: One dataset in R and Python

Bioinformatics · R

Modern Statistics for Modern Biology

Susan Holmes and Wolfgang Huber

Statistics for high-throughput biology with R and Bioconductor: multiple testing, clustering, RNA-seq and more.

Goes with: the chromosome X RNA-seq project

Machine learning · Python

An Introduction to Statistical Learning, with Applications in Python

Gareth James, Daniela Witten, Trevor Hastie, Robert Tibshirani and Jonathan Taylor

The standard introduction to machine learning: regression, classification, resampling, trees and boosting, with Python labs. The PDF is free on the book’s site.

Goes with: the classifier planned for the TB BAL cytokines project

Machine learning · SHAP

Interpretable Machine Learning

Christoph Molnar

How to explain what a model has learnt, including clear chapters on Shapley values and SHAP, permutation importance and partial dependence.

Goes with: the classifier planned for the TB BAL cytokines project

Python · machine learning

Python Data Science Handbook

Jake VanderPlas

NumPy, pandas, Matplotlib and scikit-learn in one book. The free online version is the first edition.

Goes with: Tutorial 2: One dataset in R and Python and the credit risk pipeline

Git · RStudio

Happy Git and GitHub for the useR

Jenny Bryan, the STAT 545 TAs and Jim Hester

Setting up Git and GitHub with RStudio, and the everyday version-control habits that keep an analysis reproducible.
