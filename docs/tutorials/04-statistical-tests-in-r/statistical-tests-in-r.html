1. Set up

Put the two cleaned files in your project’s data/ folder and load the packages. Every test in this tutorial is part of base R; the packages are for loading, reshaping and plotting the data.

library(readr)    # read the CSV files
library(dplyr)    # data manipulation
library(tidyr)    # reshape data for paired tests
library(ggplot2)  # plots
library(here)     # file paths from the project root
metadata_path <- here("data", "bal_metadata_clean.csv")
cells_path    <- here("data", "bal_cell_counts_clean.csv")

A CSV file stores categories as plain text, so set their order again after loading. Without this, R sorts them alphabetically and every table and plot starts with “Active TB”:

metadata <- read_csv(metadata_path, show_col_types = FALSE) |>
  mutate(
    tb_diagnosis   = factor(tb_diagnosis, levels = c("Control", "LTBI", "Active TB", "Indeterminate")),
    hiv_status     = factor(hiv_status, levels = c("Negative", "Positive")),
    smoking_status = factor(smoking_status, levels = c("Never", "Former", "Current"))
  )

cell_counts <- read_csv(cells_path, show_col_types = FALSE) |>
  mutate(visit = factor(visit, levels = c("Baseline", "Month3", "Month6", "Month12")))

# One row per participant: their details plus their baseline cell counts
baseline <- metadata |>
  inner_join(filter(cell_counts, visit == "Baseline"), by = "pt_id")

2. How to choose a test

Every test answers a version of the same question: could the pattern in this sample just be chance? The answer comes as a p-value.

TipReading a p-value

Every test starts by assuming there’s no real difference between the groups (or no real link between two variables). This starting assumption is called the null hypothesis. The p-value then asks:

If there were no real difference, how likely is it that chance alone would give a difference at least as big as the one in our data?

  • A small p-value (below 0.05) means a difference this big would rarely happen by chance alone. The data would be surprising if the null hypothesis were true, so we reject the null hypothesis and conclude there’s probably a real difference: the result is statistically significant.
  • A large p-value (0.05 or above) means a difference this big could easily happen by chance. The data gives no evidence of a real difference.

For example, p = 0.03 means that if there were no real difference, chance alone would produce a difference at least this large only about 3 times in 100.

The cut-off of 0.05 (1 in 20) is a convention, called the significance level and written α (alpha). Choose it before you look at the results, not after (Vu and Harrington, 2020, sec.4.3).

Three things a p-value doesn’t tell you:

  1. How big or important the difference is. In a large study, even a tiny, unimportant difference can have a very small p-value. Always look at the means or medians too.
  2. That the groups are the same. A large p-value means “we found no evidence of a difference”, not “there is no difference”. The study may simply be too small to tell.
  3. The chance that the null hypothesis is true. It’s the chance of the data, assuming the null hypothesis is true, not the other way round.

Read more: Vu and Harrington (2020, sec.4.3) for hypothesis testing and p-values, and section 4.2 for confidence intervals (free PDF).

To choose a test, answer three questions about your data:

  1. What kind of outcome is it? A measurement on a scale (BMI, cell percentages) or a category (HIV status, smear result)?
  2. How many groups are you comparing? Two, or three or more?
  3. Are the groups independent or paired? Different people in each group, or the same people measured twice?

For measurements, there’s a fourth: do the values roughly follow a normal (bell-shaped) distribution? Tests that assume this are called parametric. Their non-parametric alternatives work on the ranks of the values instead, so they don’t need it. The price is a little less power when the data really is normal: the Wilcoxon rank-sum test is about 95% as powerful as the t-test (Childs, Hindle and Warren, 2021, sec.33.8). So use the parametric test when its assumptions hold, and the rank-based one when they don’t.

Outcome Comparison Values look normal Values don’t look normal
Measurement 2 independent groups Welch’s t-test Wilcoxon rank-sum test
Measurement 3 or more independent groups One-way ANOVA Kruskal-Wallis test
Measurement Same people, 2 time points Paired t-test Wilcoxon signed-rank test
Category 2 categorical variables Chi-square test Fisher’s exact test (small counts)
Measurement 2 measurements, same people Pearson correlation Spearman correlation

The rest of this tutorial works through that table, one test at a time.

3. Check the assumptions first

The parametric tests assume the values in each group come from a roughly normal distribution. There are two ways to check.

Look at the data. A histogram shows the shape. A Q-Q plot (quantile-quantile plot) is more precise: it plots the values against what a normal distribution would give, so normal data falls along the straight line.

baseline |>
  select(bmi, neutrophils_percent) |>
  pivot_longer(everything(), names_to = "measurement", values_to = "value") |>
  ggplot(aes(sample = value)) +
  stat_qq(alpha = 0.4) +
  stat_qq_line(colour = "#E36414") +
  facet_wrap(~ measurement, scales = "free") +
  labs(x = "Expected if normal", y = "Observed") +
  theme_minimal()

Test it. The Shapiro-Wilk test has the null hypothesis “these values come from a normal distribution”. A small p-value (below 0.05) is evidence that they don’t. Check each group separately, because the assumption applies to each group:

baseline |>
  filter(!is.na(bmi)) |>
  group_by(tb_diagnosis) |>
  summarise(n = n(), shapiro_p = shapiro.test(bmi)$p.value)
# A tibble: 4 × 3
  tb_diagnosis      n shapiro_p
  <fct>         <int>     <dbl>
1 Control         108    0.926 
2 LTBI            153    0.0980
3 Active TB       163    0.350 
4 Indeterminate    73    0.153

Every group has p above 0.05, so BMI looks normal in all four groups.

WarningDon’t rely on the Shapiro-Wilk test alone

With large groups, Shapiro-Wilk flags tiny departures from normality that don’t matter; with small groups, it misses big ones. Use it together with the plots, not instead of them. Look mainly for strong skew and outliers, the departures that cause real problems (Vu and Harrington, 2020, sec.5.1). And the t-test and ANOVA cope with mild non-normality once the groups are reasonably large.

The normal distribution, and how to judge whether data follows it with a Q-Q plot, are in Vu and Harrington (2020, sec.3.3) (free PDF).

4. Comparing two groups

Welch’s t-test

NoteAbout Welch’s t-test

What it does: compares the means of a measurement in two independent groups. It divides the difference between the two sample means by its standard error, the amount that difference would vary by chance from one sample to the next. The further this t statistic is from 0, the less likely the difference is to be chance.

Use it when: the outcome is a numeric measurement, there are two groups of different people, and the values in each group look roughly normal.

Assumptions, most important first (Childs, Hindle and Warren, 2021, sec.13.2):

  1. Independent observations. Each person appears once, and one person’s value doesn’t affect another’s. This matters most: even mild dependence makes p-values too small, and only the study design can tell you whether it holds.
  2. A numeric measurement, not a category or a score.
  3. Roughly normal values in each group. Check each group on its own, not the combined data. The test copes with mild departures in larger samples: about 30 or more per group (Vu and Harrington, 2020, sec.5.1), and comfortably above 100 (Childs, Hindle and Warren, 2021, sec.13.2).

The classic Student’s t-test also assumes the two groups have the same spread (variance). Welch’s version doesn’t, which is why R uses it by default. When the spreads really are equal, Student’s test is only slightly more powerful, so Welch’s is the safer choice (Childs, Hindle and Warren, 2021, sec.13.2).

In R: t.test(outcome ~ group, data = ...)

Read more: Vu and Harrington (2020, sec.5.3) (free PDF); chapter 13 of Childs, Hindle and Warren (2021).

Question: do participants with active TB have a different BMI from controls? BMI looked normal in every group (section 3), so a t-test fits. Keep just the two groups, then run it:

two_groups <- baseline |>
  filter(tb_diagnosis %in% c("Active TB", "Control")) |>
  mutate(tb_diagnosis = droplevels(tb_diagnosis))

t.test(bmi ~ tb_diagnosis, data = two_groups)

How to read it:

  • mean in group: the average BMI in each group, about 24.3 in controls and 25.4 with active TB.
  • t and df: the test statistic and its degrees of freedom. You report them, but the p-value is what you interpret.
  • p-value: 0.12, above 0.05, so there’s no evidence that mean BMI differs between the groups.
  • 95 percent confidence interval: the range of plausible values for the difference in means. It includes 0 (no difference), which matches the p-value.

droplevels() matters here: after filtering, tb_diagnosis still knows about the LTBI and Indeterminate levels, and t.test() needs exactly two.

Wilcoxon rank-sum test

NoteAbout the Wilcoxon rank-sum test

What it does: compares two independent groups using the ranks of the values instead of the values themselves. All the values from both groups are put in order and numbered 1, 2, 3 and so on. If one group’s values tend to be larger, its ranks add up to more than you’d expect by chance (Childs, Hindle and Warren, 2021, sec.33.2). It’s also called the Mann-Whitney U test.

Use it when: there are two groups of different people, and the outcome is skewed, has outliers, comes from small groups, or is an ordered score (such as a smear grade) rather than a measurement.

Assumptions: rank-based tests make weaker assumptions than the t-test, but they aren’t assumption-free (Childs, Hindle and Warren, 2021, sec.33.1 and 33.5):

  1. Independent observations, as for the t-test.
  2. An outcome you can put in order: a measurement or an ordered score, not a plain category.
  3. Distributions of a similar shape in the two groups, apart from where they’re centred. When that holds, the test compares the medians. When it doesn’t, a significant result only tells you that values in one group tend to be larger, not that the medians differ.

The trade-off: if the data really is normal, the test is about 95% as powerful as the t-test (Childs, Hindle and Warren, 2021, sec.33.8). That’s why the t-test is still the first choice when its assumptions hold.

In R: wilcox.test(outcome ~ group, data = ...)

Read more: section 33.5 of Childs, Hindle and Warren (2021), and R’s wilcox.test help page (or type ?wilcox.test in the console). For a related approach that also avoids assuming normality, a randomisation test, see chapter 20 of Çetinkaya-Rundel and Hardin (2024).

Question: do neutrophil percentages differ between active TB and latent TB infection (LTBI)? Section 3 showed neutrophil percentages are strongly skewed, so use the rank-based test. Plot first, then test:

active_vs_ltbi <- baseline |>
  filter(tb_diagnosis %in% c("Active TB", "LTBI")) |>
  mutate(tb_diagnosis = droplevels(tb_diagnosis))

ggplot(active_vs_ltbi, aes(tb_diagnosis, neutrophils_percent)) +
  geom_boxplot(outlier.shape = NA) +
  geom_jitter(width = 0.15, alpha = 0.3) +
  labs(x = NULL, y = "Neutrophils (%)") +
  theme_minimal()
active_vs_ltbi |>
  group_by(tb_diagnosis) |>
  summarise(n = sum(!is.na(neutrophils_percent)),
            median = median(neutrophils_percent, na.rm = TRUE))
# A tibble: 2 × 3
  tb_diagnosis     n median
  <fct>        <int>  <dbl>
1 LTBI           151    1.8
2 Active TB      157   19.5
wilcox.test(neutrophils_percent ~ tb_diagnosis, data = active_vs_ltbi, exact = FALSE)

    Wilcoxon rank sum test with continuity correction

data:  neutrophils_percent by tb_diagnosis
W = 0, p-value < 2.2e-16
alternative hypothesis: true location shift is not equal to 0

The median neutrophil percentage is about 2% with LTBI and about 20% with active TB, and the p-value is far below 0.05: strong evidence of a difference.

Check the shape assumption against the plot: the LTBI values are tightly bunched near 2%, while the active TB values are spread widely. The shapes aren’t similar, so the safe conclusion is that neutrophil percentages tend to be higher in active TB, rather than a precise statement about medians.

W is the test statistic: the number of pairs, one person from each group, in which the first group’s value (here LTBI, the first level) is the larger. W = 0 means that in every possible pair, the person with active TB had the higher neutrophil percentage: the two groups don’t overlap at all, as the plot shows. That clean separation is a feature of this simulated data. exact = FALSE tells R to use the normal approximation, which is standard when there are tied values or more than about 50 observations.

5. Comparing three or more groups

You might be tempted to run a t-test on every pair of groups. With four groups that’s six tests, and each one has a 5% chance of a false positive, so the chance of at least one false alarm climbs to about 26% (Vu and Harrington, 2020, sec.5.5). Instead, test all the groups at once.

One-way ANOVA

NoteAbout one-way ANOVA

What it does: analysis of variance (ANOVA) tests whether three or more independent groups all have the same mean. It splits the total variation in the outcome into two parts: variation between the group means, and variation within each group, from person to person. The F statistic is the ratio of the two. If the group means are further apart than the person-to-person variation would explain, F is large and the p-value small (Childs, Hindle and Warren, 2021, sec.17.3).

Use it when: the outcome is a numeric measurement, there are three or more groups of different people, and the values in each group look roughly normal.

Assumptions (Vu and Harrington, 2020, sec.5.5):

  1. Independent observations, within and across the groups.
  2. Roughly normal values in each group. As with the t-test, ANOVA copes with mild departures when the groups are reasonably large.
  3. Similar spread in each group. Compare the boxes in a boxplot, or the groups’ standard deviations.

In R: aov(outcome ~ group, data = ...), then summary() on the result.

Read more: Vu and Harrington (2020, sec.5.5) (free PDF), which also covers the multiple-comparisons problem; chapters 17 and 18 of Childs, Hindle and Warren (2021).

Question: does BMI differ across the four diagnosis groups? BMI looked normal in all four, so use ANOVA:

bmi_anova <- aov(bmi ~ tb_diagnosis, data = baseline)
summary(bmi_anova)
              Df Sum Sq Mean Sq F value Pr(>F)
tb_diagnosis   3    265   88.28   2.083  0.102
Residuals    493  20890   42.37               
3 observations deleted due to missingness

The row that matters is tb_diagnosis. F value is the test statistic (between-group variation divided by within-group variation), and Pr(>F) is the p-value: 0.10. So there’s no evidence that mean BMI differs across the four groups.

Tip

A significant ANOVA tells you that at least one group differs, not which one. Finding out which groups differ needs a post hoc test, which is in Tutorial 5.

Kruskal-Wallis test

NoteAbout the Kruskal-Wallis test

What it does: the rank-based version of one-way ANOVA. It ranks all the values across the groups, then tests whether the average rank differs between groups (Childs, Hindle and Warren, 2021, sec.33.6). With two groups it gives the same answer as the Wilcoxon rank-sum test.

Use it when: there are three or more groups of different people, and the outcome is skewed, has outliers, comes from small groups, or is an ordered score.

Assumptions: the same as the Wilcoxon rank-sum test: independent observations, an outcome you can put in order, and distributions of a similar shape in every group. Similar skew matters most: if one group is strongly skewed and another isn’t, a significant result is hard to interpret (Childs, Hindle and Warren, 2021, sec.33.6).

The trade-off: it’s less informative than ANOVA. A significant result says the groups differ, but working out which ones is harder (Childs, Hindle and Warren, 2021, sec.33.8). Tutorial 5 covers the follow-up tests.

In R: kruskal.test(outcome ~ group, data = ...)

Read more: section 33.6 of Childs, Hindle and Warren (2021), and R’s kruskal.test help page. For a randomisation approach to comparing many groups, see chapter 22 of Çetinkaya-Rundel and Hardin (2024).

Question: do macrophage percentages differ across the diagnosis groups? Cell percentages are skewed, so use Kruskal-Wallis:

ggplot(baseline, aes(tb_diagnosis, macrophages_percent)) +
  geom_boxplot(outlier.shape = NA) +
  geom_jitter(width = 0.15, alpha = 0.2) +
  labs(x = NULL, y = "Macrophages (%)") +
  theme_minimal()
kruskal.test(macrophages_percent ~ tb_diagnosis, data = baseline)

    Kruskal-Wallis rank sum test

data:  macrophages_percent by tb_diagnosis
Kruskal-Wallis chi-squared = 390.9, df = 3, p-value < 2.2e-16

The p-value is extremely small: macrophage percentages clearly differ between the diagnosis groups. The plot shows where: participants with active TB have far fewer macrophages, because more of their BAL cells are lymphocytes and neutrophils. df is the number of groups minus one.

As with the Wilcoxon example, the groups’ shapes aren’t identical: the active TB values are much more spread out. So read this as “macrophage percentages tend to be lower in active TB”, and use the follow-up tests in Tutorial 5 to compare specific groups.

6. Paired measurements

Paired t-test and Wilcoxon signed-rank test

NoteAbout paired tests

What they do: compare two measurements taken on the same participants, such as before and after treatment. Instead of comparing two groups, they work out each person’s change and test whether the changes are centred on zero.

Use them when: each value in one set has a partner in the other: the same person at two visits, two samples from the same patient, or matched pairs.

Why pairing helps: people differ a lot from one another. Comparing each person with themselves removes that person-to-person variation, so a paired test can detect much smaller changes (Childs, Hindle and Warren, 2021, sec.20.2). Treating paired data as two independent groups is a common mistake, and it can hide a real effect (Vu and Harrington, 2020, sec.5.3).

Assumptions:

  • Paired t-test: the pairs are independent of each other, and the differences are roughly normal. The original values don’t need to be normal, and differences are often close to normal even when the values aren’t (Childs, Hindle and Warren, 2021, sec.20.3).
  • Wilcoxon signed-rank test: the pairs are independent, and the differences are roughly symmetric around their centre, though not necessarily normal (Childs, Hindle and Warren, 2021, sec.33.4).

How R pairs the values: given two vectors, R pairs them by position: the first value with the first, the second with the second (Childs, Hindle and Warren, 2021, sec.20.4). Make sure each row holds one person’s two measurements, as pivot_wider() does below.

In R: t.test(after, before, paired = TRUE) or wilcox.test(after, before, paired = TRUE)

Read more: Vu and Harrington (2020, sec.5.2) (free PDF) and chapter 20 of Childs, Hindle and Warren (2021) for the paired t-test; section 33.4 of Childs, Hindle and Warren (2021) for the Wilcoxon signed-rank test; chapter 21 of Çetinkaya-Rundel and Hardin (2024) for a randomisation version.

Question: in participants with active TB, does the neutrophil percentage change between baseline and month 6? Put each participant’s two visits side by side with pivot_wider(), keeping only people with both:

neutrophils_paired <- cell_counts |>
  filter(visit %in% c("Baseline", "Month6")) |>
  inner_join(select(metadata, pt_id, tb_diagnosis), by = "pt_id") |>
  filter(tb_diagnosis == "Active TB") |>
  select(pt_id, visit, neutrophils_percent) |>
  pivot_wider(names_from = visit, values_from = neutrophils_percent) |>
  filter(!is.na(Baseline), !is.na(Month6)) |>
  mutate(change = Month6 - Baseline)

nrow(neutrophils_paired)
[1] 85

7. Two categorical variables

Chi-square test of independence

NoteAbout the chi-square test

What it does: tests whether two categorical variables are associated: whether knowing one tells you something about the other. Assuming there’s no association, it works out the count you’d expect in each cell of the table: the row total times the column total, divided by the overall total (Vu and Harrington, 2020, sec.8.3). The chi-square statistic adds up how far each observed count is from its expected count. The bigger the mismatch, the smaller the p-value.

Use it when: both variables are categories (HIV status, smear result) and each person is counted once.

Assumptions:

  1. Independent observations. Each person falls in exactly one cell. That rules out, for example, before-and-after measurements on the same people (Childs, Hindle and Warren, 2021, sec.32.2).
  2. Large enough expected counts, checked on the expected counts, not the observed ones. The rules of thumb differ: at least 5 in every cell (Childs, Hindle and Warren, 2021, sec.32.2), or more cautiously at least 10 (Vu and Harrington, 2020, sec.8.3). Below that, the p-value isn’t reliable: use Fisher’s exact test instead.

In R: chisq.test(table(variable_1, variable_2))

Read more: Vu and Harrington (2020, sec.8.3) (free PDF); chapter 32 of Childs, Hindle and Warren (2021).

Question: among people with active TB, is a negative sputum smear more common in people living with HIV? Make the table first:

active_tb <- baseline |>
  filter(tb_diagnosis == "Active TB") |>
  mutate(smear = if_else(smear_grade == "Negative", "Smear negative", "Smear positive"))

smear_hiv <- table(active_tb$smear, active_tb$hiv_status)
smear_hiv
                
                 Negative Positive
  Smear negative       17       24
  Smear positive       81       42

Check the expected counts, then run the test:

smear_test <- chisq.test(smear_hiv)
smear_test$expected
                
                 Negative Positive
  Smear negative     24.5     16.5
  Smear positive     73.5     49.5
smear_test

    Pearson's Chi-squared test with Yates' continuity correction

data:  smear_hiv
X-squared = 6.6263, df = 1, p-value = 0.01005

Every expected count is above 10, so the test is valid by either rule of thumb. The p-value is below 0.05: smear results and HIV status are associated. The table shows the direction: 24 of 66 people living with HIV had a negative smear (36%), against 17 of 98 HIV-negative people (17%).

For a 2×2 table, R applies Yates’ continuity correction by default, which makes the test slightly more cautious. That’s why the output says “with Yates’ continuity correction”.

Fisher’s exact test

NoteAbout Fisher’s exact test

What it does: answers the same question as the chi-square test, whether two categorical variables are associated. Instead of an approximation that needs large counts, it calculates the p-value exactly, from every way the counts could have been arranged given the table’s row and column totals.

Use it when: the expected counts are too small for the chi-square test: below 5, or below 10 by the more cautious rule (Vu and Harrington, 2020, sec.8.3). It’s usually used for 2×2 tables. R can run it on larger tables, but the calculation gets heavy.

Assumptions: independent observations. There’s no minimum count.

In R: fisher.test(table(variable_1, variable_2))

Read more: Vu and Harrington (2020, sec.8.3) (free PDF).

The interval is very wide (it runs from well below 1 to well above it), which is what small numbers look like: the data is compatible with anything from much lower to much higher odds of resistance in children.

8. Two measurements: correlation

NoteAbout correlation

What it does: measures how strongly two measurements on the same people move together, as a coefficient from −1 to +1. Near +1: when one is high, so is the other. Near −1: when one is high, the other is low. Near 0: no relationship. cor.test() also tests whether the coefficient differs from zero.

Pearson’s r measures a straight-line (linear) relationship. Its assumptions (Childs, Hindle and Warren, 2021, sec.14.1):

  1. Both variables are numeric measurements.
  2. Both are roughly normal; this matters for the p-value.
  3. The relationship is linear: the scatter plot looks like a line, not a curve. It’s also sensitive to outliers, so always plot first.

Spearman’s rho is Pearson’s r calculated on the ranks. It measures whether one variable tends to rise (or fall) as the other rises, in a straight line or not: a monotonic relationship. It works for skewed data and ordered scores. Its assumptions (Childs, Hindle and Warren, 2021, sec.33.7):

  1. Both variables can be put in order.
  2. The relationship is monotonic. Don’t use it if the scatter plot forms a hill or a valley.

When Pearson’s assumptions do hold, Spearman’s is somewhat less powerful (roughly 91% in some evaluations) (Childs, Hindle and Warren, 2021, sec.33.7).

In R: cor.test(x, y, method = "pearson") or cor.test(x, y, method = "spearman")

Read more: correlation and scatterplots in Vu and Harrington (2020, sec.1.6 and 6.1) (free PDF) and chapter 14 of Childs, Hindle and Warren (2021). For Spearman’s rho, see section 33.7 of Childs, Hindle and Warren (2021) and R’s cor.test help page.

Question: do people with a stronger IGRA response have more lymphocytes in their BAL fluid? Plot it first, as always:

ggplot(baseline, aes(igra_value_iu_ml, lymphocytes_percent)) +
  geom_point(alpha = 0.4) +
  labs(x = "IGRA value (IU/ml)", y = "Lymphocytes (%)") +
  theme_minimal()

WarningCorrelation is not causation

This association doesn’t mean a stronger IGRA response causes more lymphocytes, or the reverse. In this dataset, both are highest in participants with active TB, so TB diagnosis may drive both. A third variable behind an association is called a confounder; regression, in Tutorial 5, is one way to account for it.

9. How big is the difference? Effect size and power

A p-value tells you whether a difference is likely to be real, not whether it matters. Statistical significance isn’t the same as biological or clinical importance. In one river study, water pH differed significantly between open water and weed beds (p < 0.01), but the means were 7.1 and 6.9: a real difference, and almost certainly an unimportant one (Childs, Hindle and Warren, 2021, sec.10.3). Two more ideas complete the picture: effect size (how big is it?) and power (could the study have found it?).

Effect size

NoteAbout effect size

What it is: a measure of how big a difference or association is. Unlike a p-value, it doesn’t shrink just because the study is large.

In the original units: the difference between the group means (or medians), with its 95% confidence interval. This is usually the most useful version, because readers can judge directly whether it matters: is a difference of 1 kg/m² in BMI important? The confidence interval shows the range of differences the data is compatible with (Vu and Harrington, 2020, sec.4.2).

Standardised: Cohen’s d is the difference in means divided by the pooled standard deviation, so it’s measured in standard deviations. That lets you compare effects across measurements with different units. Cohen’s rough guide is 0.2 for a small effect, 0.5 medium and 0.8 large (Cohen, 1988), but what counts as important depends on the measurement and the setting.

Correlations are already effect sizes: Pearson’s r and Spearman’s rho measure how strong a relationship is.

Read more: Vu and Harrington (2020, sec.4.2) (free PDF) on confidence intervals; section 10.3 of Childs, Hindle and Warren (2021) on biological versus statistical significance.

Go back to the BMI comparison from section 4. t.test() already gives the effect size in the original units: the difference in means and its confidence interval. Cohen’s d takes a few lines:

bmi_summary <- two_groups |>
  filter(!is.na(bmi)) |>
  group_by(tb_diagnosis) |>
  summarise(n = n(), mean = mean(bmi), sd = sd(bmi))
bmi_summary
# A tibble: 2 × 4
  tb_diagnosis     n  mean    sd
  <fct>        <int> <dbl> <dbl>
1 Control        108  24.3  5.25
2 Active TB      163  25.4  6.30
# Difference in means (active TB minus control)
difference <- diff(bmi_summary$mean)

# Pooled standard deviation: the two groups' SDs combined, weighted by group size
pooled_sd <- with(bmi_summary, sqrt(sum((n - 1) * sd^2) / (sum(n) - 2)))

c(difference = difference, pooled_sd = pooled_sd, cohens_d = difference / pooled_sd)
difference  pooled_sd   cohens_d 
 1.1058169  5.9064981  0.1872204

Active TB participants averaged about 1.1 kg/m² more than controls, a Cohen’s d of about 0.19: a small effect, smaller than the person-to-person spread of almost 6 kg/m². The t-test’s confidence interval (section 4) runs from about 2.5 kg/m² lower to 0.3 kg/m² higher in controls, so the data is compatible with no difference or with a modest one.

Power

NoteAbout power

Two ways to be wrong: a test can find a difference that isn’t real (a Type I error, a false positive), or miss one that is (a Type II error, a false negative). The significance level, α = 0.05, is the chance of a Type I error (Vu and Harrington, 2020, sec.4.3).

What power is: the probability that a test detects a real effect of a given size, if it exists (Çetinkaya-Rundel and Hardin, 2024, chap.14). Power is 1 minus the chance of a Type II error.

What it depends on: the size of the effect (bigger effects are easier to find), the variability of the measurement, the sample size, and α.

Use it when:

  • Planning a study: choose a sample size large enough to detect the smallest difference that would matter. Studies usually aim for 80% or 90% power, and the calculated sample size is always rounded up (Vu and Harrington, 2020, sec.5.4).
  • Reading a non-significant result: if the study had little power to detect an important difference, “no evidence of a difference” may just mean “too small to tell”.

Base the calculation on the smallest difference that would matter, not on the difference you happened to observe.

In R: power.t.test() for comparing two means (power.prop.test() for two proportions). Give it all but one of n (per group), delta (the difference), sd, sig.level and power, and it calculates the missing one.

Read more: Vu and Harrington (2020, sec.5.4) (free PDF), a worked example of power and sample size for a clinical trial; chapter 14 of Çetinkaya-Rundel and Hardin (2024); R’s power.t.test help page.

Was the BMI comparison large enough to find a difference? power.t.test() assumes equal group sizes, so use the smaller group (108 controls); that errs on the cautious side. First, the smallest difference the study had an 80% chance of detecting:

But a smaller difference, like the 1.1 kg/m² seen here, can’t be ruled out: the study was too small to tell. That’s the practical meaning of “no evidence of a difference” from section 2.

10. Report a result

A result needs more than “p < 0.05”. Report what was compared, the summary values, the test, the statistic and the p-value, in one sentence:

Median baseline neutrophil percentage was higher in active TB than in latent TB infection (median 19.5% vs 1.8%; Wilcoxon rank-sum test, W = 0, p < 0.001; n = 157 and 151).

Some conventions:

  • Give exact p-values to two significant figures (p = 0.12), and “p < 0.001” for anything smaller.
  • Report means with a t-test or ANOVA, and medians with the rank-based tests.
  • Report the size of the difference with its confidence interval, not just whether it’s significant.
  • Say how many people were in each group, and how many were left out because of missing values.

Common pitfalls

Problem Symptom Fix
Choosing the test after seeing the results Trying tests until one gives p < 0.05 Choose the test from the data type and design, before testing
Many pairwise t-tests False positives across lots of comparisons Test all groups at once (ANOVA, Kruskal-Wallis); post hoc tests in Tutorial 5
Unpaired test on paired data Real changes look non-significant Use a paired test whenever the same people are measured twice
Chi-square with small counts R warns “approximation may be incorrect” Check expected counts; use Fisher’s exact test
Leftover factor levels t.test() complains about more than two groups droplevels() after filtering
“Not significant” read as “no difference” Claiming groups are the same Say “no evidence of a difference” and look at the confidence interval
Only reporting p-values Readers can’t judge how big the difference is Report the effect size with its confidence interval, plus the statistic and group sizes
Significant read as important A tiny difference reported as a finding Judge the effect size, not the p-value
Small study, no power Real differences come out non-significant Plan the sample size with power.t.test() before collecting data
